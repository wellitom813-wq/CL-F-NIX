PARA ADICIONAR UM LAYOUT REAL
1. Coloque a imagem em assets/layouts/
2. Abra layouts.json
3. Edite uma entrada ou copie uma existente.
4. Preencha o campo link com o link oficial de compartilhamento do Clash of Clans.

Exemplo:
{
  "id": 101,
  "cv": 18,
  "tipo": "Guerra",
  "nome": "Anti-3 Estrelas #101",
  "descricao": "Base de guerra CV18.",
  "imagem": "assets/layouts/cv18-101.jpg",
  "link": "https://link.clashofclans.com/...",
  "tags": ["Guerra", "Anti-3", "CV18"],
  "destaque": true,
  "data": "2026-08-09"
}

Se a imagem não existir, a página mostra um placeholder bonito.
Se o link estiver vazio, o botão fica como 'Link em breve'.
Não precisa mexer na Vultr, PM2, token ou API.
