FENIX API - BACKEND

1. Coloque server.js no GitHub.
2. No servidor Vultr, entre em:
   cd /var/www/fenix-api

3. Baixe server.js do GitHub usando curl.
4. Crie o arquivo .env no servidor com:
   COC_CLAN_TAG=#VJ8GGLR8
   COC_API_TOKEN=SEU_TOKEN
   PORT=3000

5. Rode:
   node server.js

IMPORTANTE:
- Nunca coloque o token real no GitHub.
- O token deve ficar apenas no arquivo .env do servidor.
