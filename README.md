# Clã Fênix - versão sem API com membros reais

Esta versão usa os dados legíveis nas imagens enviadas.

Campos usados com segurança:
- nome
- cargo
- CV
- BC
- nível
- posição no clã

Os demais números e ícones das capturas não foram nomeados para evitar interpretar uma estatística de forma errada.

## Arquivos
- index.html
- style.css
- script.js

## Onde editar os membros
Abra `script.js` e procure `const MEMBROS = [`.

As posições 2 a 7 e alguns nomes em caracteres asiáticos não foram incluídos porque não estavam legíveis/visíveis o suficiente nas capturas atuais.
